Designed for Precision, Traceability, and Safety

A dependable, rule-bounded architecture that strictly avoids medical speculation.

Enhanced Image Pipeline

Converts low-quality scans, wrinkled paper reports, and camera photos using bilateral filtering, CLAHE contrast enhancement, sharpening, and automated deskewing before OCR.

Reference-Range Awareness

Evaluates laboratory values exclusively against reference ranges stated directly in the source report. If no range is provided, status is strictly marked as Not determined.

Provenance & Verification

Tracks the origin of every data point (User Provided, Extracted from Report, AI Generated). Includes an interactive side-by-side verification screen to confirm or correct values before storage.

Data Privacy & Security
  • API keys and credentials are stored strictly in server-side environment variables and never exposed to the client.
  • All uploads are validated for safe file types, sanitized filenames, and size limits (16MB).
  • Patient data is stored in a structured relational database with parameterized queries preventing SQL injection.
  • No patient data is ever sold or utilized for training external AI models.
Clinical Safety Guarantee
  • NO Medical Diagnosis: The system will never guess, assert, or predict illnesses or diseases.
  • NO Treatment Advice: The AI does not suggest medications, therapies, or clinical interventions.
  • NO Silent Number Alteration: Questionable values (e.g. 13 vs 1.3 mg/dL) are flagged for human review.
  • Auditable: Every lab result preserves its original text string alongside the parsed numeric float.
